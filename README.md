# Olivierpironneau Freefem

## How do I install these formulae?

`brew install olivierpironneau/freefem/<formula>`

Or `brew tap olivierpironneau/freefem` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "olivierpironneau/freefem"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
